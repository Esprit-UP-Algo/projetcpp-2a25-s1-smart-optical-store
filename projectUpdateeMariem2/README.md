# Smart Optical Store Management System

A Qt-based desktop application for managing an optical store business. The application provides interfaces for managing products, customers, sales, and prescriptions.

## Features

- **User Authentication**: Secure login system with different user roles
- **Dashboard**: Overview of key business metrics and recent sales
- **Products Management**: Add, edit, delete, and search products
- **Customers Management**: Manage customer information and history
- **Sales Management**: Process sales transactions and view sales history
- **Prescription Management**: Record and manage optical prescriptions
- **Modern UI**: Clean and intuitive user interface

## Technical Details

- Built with Qt and C++
- Uses SQLite database for data storage
- Modern styling with custom QSS
- Responsive layout that adapts to different screen sizes
